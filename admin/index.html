🔊 Suara ElevenLabs

Isi API Key dan dua voice: satu untuk tutor perempuan dan satu untuk tutor laki-laki. Setiap anak bisa memilih tutornya di Pengaturan → Tutor suara. Ucapan dipakai pelan & ceria (kecepatan 0.7–0.8) dan hasilnya di-cache di perangkat supaya hemat kredit. Jika kosong/gagal, aplikasi otomatis memakai suara bawaan browser.

Tombol 📋 mengambil daftar voice asli dari akunmu (pakai API key di atas) supaya Voice ID tidak salah ketik. Voice bahasa Indonesia ditandai 🇮🇩.

💾 Mode Server (hemat kredit — disarankan)

Centang untuk memakai cache audio di server: setiap teks di-generate sekali untuk semua user & semua HP, lalu dipanggil ulang tanpa kredit. API key cukup di server (file server/.env) — tidak perlu diisi di sini. Setup: lihat DEPLOY.md.

💡 Tips voice bahasa Indonesia

Gunakan tombol 📋 untuk memilih voice asli dari akunmu (hindari salah ketik Voice ID). Untuk bahasa Indonesia, pilih voice bertanda id. Pastikan API key punya izin text-to-speech (buat key baru dengan akses penuh di dashboard ElevenLabs jika muncul error missing the permission text_to_speech).
